# ECサイト顧客・リテンション分析

## 1. 背景と目的

限られた人員・リソースの中でリテンション率を高めるには、どの顧客に優先的にアプローチするかを決める必要がある。本分析では、売上の構造と顧客の購買行動を確認し、働きかけの優先順位と施策を提案した。

分析の問いは次の4点である。

1. 売上は、どの時期・市場・顧客層に依存しているか。
2. 売上への貢献が大きい顧客と、離脱のおそれがある顧客はどのセグメントか。
3. 新規顧客は、初回購入の後どの程度定着しているか。
4. 各顧客が今後再購入するかを予測でき、働きかけの優先順位付けに使えるか。

## 2. 結論

- **売上は9〜11月に集中し、全体は横ばいである。** 2010年は年間の純売上の36.2%が9〜11月に集まった。1〜11月の純売上は前年比+1.9%で、注文数の減少(−3.7%)を、1注文あたり純売上の増加(+5.8%)が補った。
- **少数の優良顧客に売上が集中している。** 優良顧客(顧客の23.9%)が顧客別売上の69.9%を占め、上位1%の顧客だけで31.0%を占める。離脱した場合の影響が大きい。
- **離脱リスクの顧客は、休眠層より再購入の見込みが高い。** 該当は706人(過去の純売上£1.36M)で、評価期間の実績では休眠層より再購入率(41.9%対24.0%)も1人あたり購入額(£308対£135)も高い。
- **新規顧客の約6割は、90日以内に2回目の購入に至っていない。** 90日以内に再購入したのは40.4%(90日間を観測できた1,017人)だった。
- **再購入は予測でき、優先順位付けに使える。** BG/NBD は購入回数・最終購入時期・観測期間の3つから予測でき(AUC 0.810、単純ルールは0.765)、予測確率の上位10%の再購入率は96.7%、下位10%は12.8%だった。ただし購入額の確保には過去の純売上が多い順のほうが強い基準だったため(上位20%の捕捉率は75.2%、予測確率順は70.7%)、予測は「再購入するか」の見分けに用い、購入額の大きさと組み合わせて使う。

## 3. 提案

| 優先度 | 施策 | 狙い・根拠 |
|---|---|---|
| 1 | 離脱リスク 706人に個別に連絡する(対象内は期待売上の高い順) | 休眠層より再購入率・購入額が高い |
| 2 | 優良顧客 1,393人の離脱の予兆を早期に検知し、先回りで連絡する | 顧客別売上の69.9%を占め、離脱した場合の影響が大きい |
| 3 | 新規顧客に、初回購入後90日以内にフォローする | 約6割が90日以内に再購入していない |
| 4 | 繁忙期(9〜11月)の前に優良・安定顧客へ事前案内を行い、在庫と人員を確保する | 売上の36.2%が9〜11月に集中する |
| 5 | 注文数を維持する(定期発注の提案など) | 注文数が前年比−3.7%と減少している |

各施策の効果の大きさは推定しておらず、本データでは検証できない。実施する場合はA/Bテスト等で測定する(設計案は `docs/analysis_report.md` の4.3節)。

## 4. データと分析手法

UCI Machine Learning Repository で公開されている「Online Retail II」を使用した。元データはリポジトリに含めていない。

- **対象**: 2009-12-01〜2011-12-09の1,067,371行(前処理後 1,024,196行)。主な列は伝票番号、商品コード、商品名、数量、取引日時、単価、顧客ID、国である。通貨は英ポンド(GBP)で、円換算は行っていない。元ファイルは2シートに分かれ、2010-12-01〜12-09が両シートに重複して収録されている。
- **分析の流れ**: 前処理のあと、売上分析、RFM 分析、コホート分析、再購入予測の順に進めた。再購入予測は、BG/NBD(購入回数・最終購入時期・観測期間から再購入確率を推定)と Gamma-Gamma(1注文あたり金額を推定)を主モデルとし、ロジスティック回帰、勾配ブースティング、最終購入が新しい順に並べる単純ルールと比較した。評価は2011-06-01時点の4,906人で行い、基準日を5時点に変えても結果を確認した。
- **主な判断**:
  - 重複期間・重複行・単価0以下・不良債権調整の伝票を除外した。24時間以内に同一顧客・同一商品・同一数量で取消された注文は、入力ミスの可能性が高いため、購入と取消の両方を除外した。
  - 純売上は、総売上(購入明細の数量×単価)から返品(取消伝票の絶対値)を引いた額とした。顧客IDのある取引に限った純売上(顧客5,837人、£16.3M、純売上全体の86.4%)を「顧客別売上」と呼び、顧客別の構成比はこの金額を分母とした。
  - 「新規顧客」は、初回購入の前12か月間に購入履歴がない顧客とした(データ開始が2009-12のため、2010-12以降の初回購入者が該当する)。
  - 予測モデルの優劣は、AUC とその95%区間(ブートストラップ)で比較した。

## 5. 限界

- 1事業者・約2年分のデータのため、結果を他の事業者に一般化することはできない。季節性の比率は、通年が揃う2010年のみで算出した。
- 顧客IDのない取引(純売上の13.6%)は、顧客単位の分析から除外した。
- データの開始が2009-12のため、2009-12コホートと2010年のコホートには既存顧客が混在し、新規顧客数の推移は判断できない。2011年12月は12/9までの部分月である。
- 重複行の除去と誤発注の相殺は分析者の判断による処理である。条件を変えた感度分析(誤発注の相殺の時間幅:なし〜30日、重複除去の有無)では、純売上(£18.87M〜£18.94M)とセグメント構成比はほぼ変わらず、返品率のみ1.3〜3.6%と条件に左右された。
- 予測モデルの AUC は基準日5時点で確認したが、購入額の捕捉率と離脱リスク内の絞り込み(期待売上順)の比較は評価期間1期間のみで、後者は標本が小さい。予測確率の絶対値は目安であり、顧客の優先順位付けに使う想定である。予測は相関に基づくもので、因果関係を示すものではない。

限界の詳細は、`docs/analysis_report.md` の5章を参照。

```
.
├── README.md
├── docs/
│   └── analysis_report.md        分析報告書
├── code/
│   ├── config.py                 共通設定(パス、基準日、元ファイルの読み込み)
│   ├── 01_load_clean.py          読み込み・結合・クレンジング
│   ├── 02_sales_overview.py      売上推移・前年比・国別・顧客集中度・返品
│   ├── 03_rfm.py                 RFM分析
│   ├── 04_cohort.py              コホート分析・90日以内再購入率
│   ├── 05_repurchase_model.py    比較対象の再購入予測
│   ├── model_common.py           05・08で共通の特徴量作成とBG/NBDの関数
│   ├── 08_bgnbd.py               主モデル(BG/NBD+Gamma-Gamma)の推定・評価・基準日5時点の安定性
│   ├── 10_lr_improvement.py      ロジスティック回帰の改善の検証
│   ├── 07_expected_value.py      セグメント別の実績・購入額の捕捉率・期待売上での並べ替え
│   ├── 09_sensitivity.py         前処理(誤発注の相殺・重複除去)の感度分析
│   └── run_all.sh                上記を順に実行
├── dashboard/                    ダッシュボード
├── tables/                       結果のCSV(tables/99_key_figures.csv に報告書の主要数値を集約)
└── figures/                      グラフ(PNG)
```

1. Python 3.10以上で、次のライブラリを用意する。`pip install pandas openpyxl numpy matplotlib scikit-learn scipy`
2. `code/data/` に、UCI Machine Learning Repository から取得した元ファイル `online_retail_II.xlsx`を置く。
3. `code/` で `bash run_all.sh` を実行する(読み込みに数分かかる)。Windows では `run_all.sh` に記載の順(01〜05、08、10、07、09、06)に `python` で実行する。

保存先は環境変数 `DATA_DIR`(元データ)、`WORK_DIR`(中間ファイル)、`OUT_DIR`(tables・figuresの親フォルダ)で変更できる。グラフの日本語フォントは、環境にあるものを自動で選ぶ。

## 付録:主な用語・指標

| 用語・指標 | 説明 |
|---|---|
| 純売上 | 総売上から返品額を引いた額 |
| 顧客別売上 | 顧客IDのある取引の純売上(期間通算で純売上が正の顧客の合計) |
| RFM | R=最終購入からの日数、F=購入伝票数、M=純売上。本分析のセグメントはRとFのスコアで分類する |
| 離脱リスク | 過去に繰り返し購入(F≧3)しながら、長期間購入していない(R≦2)顧客のセグメント |
| 新規顧客 | 初回購入の前12か月間に購入履歴がない顧客(RFMの「直近購入・低頻度」とは別の定義) |
| コホート | 初回購入月が同じ顧客の集団 |
| 90日以内の再購入率 | 初回購入の翌日から90日以内に再購入した顧客の割合 |
| BG/NBD | 購入回数・最終購入時期・観測期間の3つから再購入確率を推定する、契約のない小売で標準的なモデル |
| AUC | 再購入した顧客としなかった顧客を1人ずつ選んだとき、前者により高い確率を付けられる割合(0.5は無作為、1.0は完全) |
| 95%区間 | 評価データの顧客を重複を許して1,000回再抽出し(ブートストラップ法)、AUCの分布の2.5%点〜97.5%点で示したもの |
| 捕捉率 | 上位N%に絞った顧客が、評価期間(2011-06〜11)の購入額全体に占める割合(再購入率とは別の指標) |

そのほかの用語は `docs/analysis_report.md` の付録Aを参照。
